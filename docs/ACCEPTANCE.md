# 0.1.4 直連及背景翻譯實機驗收

以下是真實裝置及 Foundry 部署的驗收清單，並不代表已全部執行。自動化測試結果另列於 BUILD_STATUS.md。

| 情境 | 預期結果 |
| --- | --- |
| 從 0.1.0 覆蓋安裝 | 保留背景知識、逐字稿與語言設定，要求重新設定 Foundry 認證 |
| 從 0.1.1 覆蓋安裝 | 保留連線設定、加密 key、背景知識及逐字稿 |
| 從 0.1.2 覆蓋安裝 | 保留資料與原 key，診斷顯示 0.1.3 及 api-key 標頭認證 |
| Azure GPT-Live API key 認證 | 握手只用 api-key 標頭，Authorization 與 URL query 不包含 key；不跟隨 302 |
| 測試目前連線欄位 | 不要求麥克風權限、不傳音訊或背景知識、不建立歷史記錄，也不自動儲存欄位 |
| 測試時變更資源，key 留空 | 阻擋測試，不把已保存的 key 傳給另一資源 |
| 取消連線測試 | 中止測試並釋放連線，之後可再次測試或翻譯 |
| 複製／分享診斷 | 保留階段與安全錯誤碼；不包含 key、資源名稱、部署名稱、背景知識或逐字稿 |
| 舊服務權杖 | 不被當成 Foundry API key，遷移成功後清除 |
| 儲存 API key | key 不出現在一般設定、逐字稿、匯出或日誌 |
| 修改部署名稱，key 留空 | 使用同一資源已保存的 key |
| 修改資源端點，key 留空 | 要求重新輸入，避免舊 key 被送往另一資源 |
| 移除 API key | 重新開啟 App 仍為未設定狀態 |
| 明文 HTTP、非 Azure 端點、含帳密網址 | 開始前阻擋，沒有傳送 API key |
| 重新導向回應 | 不追蹤轉址或將 key 傳往轉址目標 |
| 拒絕麥克風權限 | 顯示麥克風提示並釋放工作階段 |
| 無效 key／無權限／部署不存在 | 顯示對應提示，不洩露認證或完整請求 |
| 自動來源、印度英文、繁體中文 | 原文與目標語字幕各自出現；人工核對品質 |
| 切換背景知識 | 新會話使用所選術語，不朗讀背景全文 |
| 手動發言者標記 | 標記接下來收到的原文，可於歷史內容修正 |
| 原文／譯文交錯抵達 | 上方原文、下方譯文；各軌依時間舊到新、持續自動捲至最末，不假造逐句配對 |
| 即時字幕 vs. 歷史及匯出 | 即時字幕不印時間戳；歷史檢視及 SRT／VTT／TXT／JSON 匯出仍保留原始時間 |
| 開始後立即停止 | 麥克風與連線釋放，能重新開始 |
| 正常停止 | 最後已擷取音訊送完，持續接收最後字幕再結束 |
| 網路中斷／服務長時間無回應 | 停止收音、保留已收到內容，不自動重連錄音 |
| Android 按 Home、切其他 App、鎖定螢幕 | 麥克風、前景服務通知與 GPT-Live 連線仍持續，新字幕在回到 App 後可看到 |
| Android 翻譯啟動後立刻進入背景 | 必須先在可見畫面啟動前景服務；服務建立後才能進入背景，避免 Android 14+ 限制 |
| Android 通知「停止並儲存」 | 停止收音與 WebSocket，保存逐字稿，通知消失；回到 App 可重新開始 |
| Android 關閉 App 畫面／最近使用清單移除 Activity | 前景服務及翻譯不中斷；點通知可回 App 查看原工作階段 |
| Android 強制停止 App／清除服務／重新開機 | 不自行重啟麥克風；既有已寫入逐字稿可從歷史讀取 |
| Android 拒絕通知權限 | 不影響已授權的麥克風；在系統允許的入口仍可停止，建議重新開啟通知 |
| Android 來電／音訊路由改變 | 可能中止錄音，應安全停止並保存，不能自動偷偷恢復 |
| iOS 切入背景 | 仍依 iOS 既有政策停止收音，未宣稱支援 iOS 背景翻譯 |
| SRT／VTT 匯出 | 字幕播放器可開啟，軌道與時間正確 |
| 重新啟動 App | 設定、背景知識、逐字稿與加密 key 正確保存 |
| 刪除歷史記錄 | 確認後只刪除所選記錄 |

測試時請記錄裝置、OS、App 版本、模型部署名稱與時間；不要把 API key 放進報告。
